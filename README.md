# PXE 装机台

跑在一台 x86_64 移动小主机上的 Linux 装机设备。小主机插上自己的装机网口，给目标服务器提供 DHCP、TFTP 和启动菜单。

- 菜单里自选 Ubuntu、Debian、Rocky Linux 或 AlmaLinux，按配置无人值守安装。
- 也可以按 MAC 绑定某台机器，超时后直接安装。
- 没有绑定的机器，菜单超时后从本地硬盘启动，避免误装机。

管理口不要接到装机交换机上。DHCP 只监听配置里的装机网口。

## 项目、临时地址和固定网络

总览只查看当前状态。新建项目时只建立目录。安装设置、DHCP、装完后的网络和 IPMI 写在项目里面。

打开一个项目的开关后，装机使用这一套：临时地址池、安装菜单、按序列号匹配的网卡和 IPMI。同时只能启用一个项目，打开另一个会关掉当前这个。没有打开的项目时，不分配装机地址。

装完后的网络是单独一块。一台机器可以有多块网卡，每一条都要写明是哪一块：填这块网卡的 MAC，或填接口名。网关可以留空，表示这块网卡不设默认路由。安装结束时按序列号领取这些网卡，按 MAC 或接口名写入，不会去猜第一块网卡。

项目里可以下载 Excel 模板。一行一块网卡，同一序列号可以有多行。表头用「序列号、网卡MAC 或网卡名、网卡IP、IPMI地址」。MAC 列是启动网卡，用来归到机器列表。

DHCP 地址池必须和小主机地址在同一个子网。

## 按序列号设置 IPMI

在「IPMI」页按序列号登记 BMC 网络：固定地址或 DHCP、掩码、网关、通道，可选 VLAN。序列号会去掉空格并转成大写，和主板 DMI 的 `product_serial` 对齐。

安装结束时，目标机读取自己的序列号，向小主机领取匹配的设置，再用带内 `ipmitool` 写入。对不上就跳过。断网安装时，把 `ipmitool` 加进安装配置的软件包，否则目标系统里可能没有这个命令。

## 接线

1. 小主机装 Ubuntu 或 Debian，安装 Docker 和 Compose 插件。
2. 装机网口（默认 `eth1`）接到一台交换机。目标服务器的 PXE 网口也接到这台交换机。
3. 给装机网口配上控制台里的地址，默认是 `192.168.77.1/24`。不要让办公室的路由器也在这张网上发 DHCP。

```bash
sudo ip addr add 192.168.77.1/24 dev eth1
sudo ip link set eth1 up
```

## 启动

```bash
./scripts/fetch-ipxe.sh
docker compose up -d --build
```

控制台是 [http://127.0.0.1:43123](http://127.0.0.1:43123)。目标机通过 80 端口取内核、ISO 和应答文件。

改过装机网口或地址池之后，执行：

```bash
docker compose restart dnsmasq
```

本机只看界面、不启动 DHCP 时：

```bash
cd console
npm install
npm run dev
```

开发服务器同样监听 43123，数据写在仓库的 `data/`。

## 导入镜像

把 ISO 放到 `data/incoming/`，在「镜像」页导入。控制台用 `xorriso` 识别家族并抽出内核。大于 256MB 的文件不要走浏览器上传。

支持：

| 家族 | 应答 | 安装源 |
| --- | --- | --- |
| Ubuntu | autoinstall | ISO 本身 |
| Debian | preseed | 展开后的安装树 |
| Rocky Linux / AlmaLinux | kickstart | 展开后的安装树 |

然后在「安装配置」里写主机名、用户、密码和磁盘策略。主机名可以用 `srv-{{mac_last4}}`。磁盘策略会清空所选磁盘，菜单文案会标明这一点。

## 现场确认

1. 打开控制台，确认 UEFI 和 BIOS 固件都是「已就位」。
2. 目标机从网卡启动，应看到「PXE 装机台」菜单，超时后回到本地硬盘。
3. 需要装机时，再选安装项，或先按 MAC 绑定。

## 目录

- `console/`：控制台和应答、菜单生成
- `deploy/`：dnsmasq 与 nginx
- `data/`：ISO、租约。不进 Git
